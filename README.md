# KisanSetu

[Open the live demo](https://himancer.github.io/kisansetu/)

KisanSetu is a static, hackathon-ready farmer prototype. It has no build step, paid API, server database, or third-party account requirement.

## What the prototype includes

- The original farmer sign-in dashboard and visual theme.
- A 13-language selector: English, Hindi, Kannada, Tamil, Telugu, Marathi, Gujarati, Bengali, Punjabi, Malayalam, Odia, Assamese, and Urdu.
- Kisan Gyan with the expanded seed, flower/herb, and home-waste manure content.
- Government Schemes with location-aware state service portals plus official links to PM-KISAN, PM Fasal Bima Yojana, Farmers’ Portal, and Soil Health Card.
- A crop and fertiliser planning demo, weather panel, farm services, and crop-photo demo interaction.

## Important prototype boundaries

The name entry is browser-local, not a production account. The Government Schemes page links only to official portals; it does not determine eligibility or collect Aadhaar, bank, or scheme-login details. Crop-photo results are demonstration content, not a real diagnosis or treatment recommendation.

## Deployment

The repository is deployed through GitHub Pages. To deploy a fork, enable **Settings → Pages → Deploy from a branch**, then choose `main` and the repository root.
